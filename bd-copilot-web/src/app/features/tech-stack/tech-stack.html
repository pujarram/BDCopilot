Technology stack

One stack, two environments. Everything below the "AI" row is identical between your laptop and production — only the model provider changes, through the Semantic Kernel abstraction described in Architecture.

AI — productionAzure OpenAI · gpt-4o for chat & drafting, text-embedding-3-large for embeddings

Local ⇄ production, side by side

Local Ollama

  • Runs entirely on the developer's machine
  • Zero token cost while iterating on prompts
  • No customer data ever leaves the laptop
  • Selected by Ai:Provider = "Ollama" in appsettings.Development.json

Production Azure OpenAI

  • Entra ID / managed-identity authenticated
  • Enterprise content filtering & regional residency
  • Higher-quality generation for client-facing documents
  • Selected by Ai:Provider = "AzureOpenAI" in appsettings.Production.json

The swap is one setting, resolved at startup by SemanticKernelFactory in backend/src/BDCopilot.Infrastructure/Services/SemanticKernelFactory.cs — it is never a client-side toggle, which is why Settings is read-only:

// backend/src/BDCopilot.Api/appsettings.Development.json
{
  "Ai": {
    "Provider": "Ollama",
    "Ollama": { "Endpoint": "http://localhost:11434", "ChatModel": "llama3.1:8b", "EmbeddingModel": "nomic-embed-text" }
  }
}
// backend/src/BDCopilot.Api/appsettings.Production.json
{
  "Ai": {
    "Provider": "AzureOpenAI",
    "AzureOpenAI": { "Endpoint": "https://bd-copilot.openai.azure.com", "ChatDeployment": "gpt-4o", "EmbeddingDeployment": "text-embedding-3-large" }
  }
}

Metadata schema

Defined in backend/src/BDCopilot.Core/Models/Document.cs and DocumentChunk.cs, mapped by EF Core in BdCopilotDbContext — this is what every citation chip in Chat and Knowledge Search resolves against:

Documents
  Id · FileName · FileType · Owner · TeamsChannel · SharePointUrl
  CreatedAt · ModifiedAt · AclHash // revalidated live at query time, never trusted alone

DocumentChunks
  Id · DocumentId (FK) · Content · Locator // e.g. "p.4", "Slide 12"
  Embedding vector(1536) // Pgvector.Vector column, cosine-searched via .CosineDistance()

Where to look in the repo

Frontend workspace: bd-copilot-web/ (Angular 20, standalone components, signals). API: backend/src/BDCopilot.Api/ — run it and open /swagger. Domain models and interfaces: backend/src/BDCopilot.Core/. Real implementations (EF Core, Semantic Kernel, blob storage, Hangfire jobs): backend/src/BDCopilot.Infrastructure/ and backend/src/BDCopilot.SyncJobs/.
