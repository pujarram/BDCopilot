System architecture

Two flows share one brain for knowledge, and the same API powers pursuit, delivery, and governance. An indexing pipeline keeps vector stores current with SharePoint, Teams, Planner, and battlecards; a query / generation pipeline answers Teams chat and drafts RFPs — only after permission checks — then multi-approval, compliance checklist, and an audit trail gate export.

Why security trimming happens twice

Indexing stores each chunk's SharePoint ACL as metadata, but access changes constantly — someone leaves a team, a file gets restricted. Trusting a stale permission copied in at index time is the most common way these systems leak. The API re-checks the live ACL through Graph on every single query, before any chunk reaches the model.

What this codebase implements today

Phases 1–9 of the product roadmap are in the running application — knowledge, generators, pursuits, analytics, Project Intelligence, and export governance share one stack.
